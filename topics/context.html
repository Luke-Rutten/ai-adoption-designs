Context

Managing what actually ends up in the context window — pulling the right content in with RAG, keeping untrusted content from hijacking the model, compacting history as it grows, and carrying state across sessions.

Overview

Placeholder — why what's in the context window matters as much as the model itself: a model is only as good as what it's been given to work with, and context is finite, costly, and sometimes adversarial.

Key question: for any given turn, what actually needs to be in context right now — versus retrievable later, summarized away, or left out entirely?

RAG

Placeholder — retrieval-augmented generation as a way to pull in relevant content on demand instead of stuffing everything into the prompt up front. Chunking, embeddings, retrieval quality, and when RAG beats just widening the context window.

Injection

Placeholder — prompt injection as the risk that untrusted content pulled into context (web pages, documents, tool output) carries instructions the model shouldn't follow. Treating retrieved content as data, not commands, and where that boundary needs to be enforced.
