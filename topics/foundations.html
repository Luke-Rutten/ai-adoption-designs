Primitives — and when to use each

Placeholder — a decision framework for choosing between these, roughly in order of increasing machinery and commitment.

PrimitiveWhat it isReach for it when…
RAGRetrieve relevant content, inject into contextKnowledge is large, changes often, and doesn't need to be "always on"
SkillPackaged instructions + optional scripts, loaded on demandA repeatable task has a known best procedure worth codifying
MCP serverStandard protocol exposing tools/resources to any clientYou need the same tool available across multiple agent clients
PluginBundle of skills, agents, commands, hooks distributed togetherYou're packaging a capability for other teams to install
SubagentA separate agent invocation with its own contextA task needs isolation, parallelism, or a different tool scope
MemoryPersisted state read back into future sessionsContinuity across sessions matters more than a clean context
